# AI Question Answering Chatbot

## Project Overview

AI Question Answering Chatbot is a simple and interactive web application developed using Python and Streamlit. The application allows users to enter questions and receive AI-generated answers using a Large Language Model (LLM).

The chatbot uses the Hugging Face Inference API to communicate with the `openai/gpt-oss-120b` model and generate responses based on the user's question.

This project demonstrates how Artificial Intelligence, Large Language Models, APIs, and Streamlit can be combined to create a simple AI-powered chatbot application.

## Features

* Simple and user-friendly chatbot interface
* Allows users to enter questions using a text area
* Generates AI-powered responses
* Uses Hugging Face Inference API
* Uses the `openai/gpt-oss-120b` Large Language Model
* Displays the generated response directly in the application
* Provides a loading indicator while generating the answer
* Displays a warning when the user submits an empty question
* Secure API key management using Streamlit Secrets
* Lightweight and easy to run locally
* Suitable for beginners learning AI and Streamlit

## How the Application Works

The application follows a simple process:

1. The user opens the Streamlit application.
2. The application displays a question input area.
3. The user enters a question.
4. The user clicks the "Ask AI" button.
5. The application sends the question to the Hugging Face Inference API.
6. The selected Large Language Model processes the question.
7. The generated response is returned by the API.
8. The answer is displayed on the Streamlit interface.

## Hugging Face API Token Setup

This project requires a Hugging Face API token to communicate with the AI model.

Create a Hugging Face access token and store it using Streamlit Secrets.

Create the following folder inside your project:

```text
.streamlit
```

Inside the folder, create:

```text
secrets.toml
```

Add your token in the following format:

```toml
HF_TOKEN = "your_huggingface_token"
```

The application accesses the token using:

```python
st.secrets["HF_TOKEN"]
```

Do not upload your actual API token to GitHub.

## Running the Application

Open the project folder in VS Code.

Open the terminal and run:

```bash
streamlit run app.py
```

After running the command, Streamlit will start the application and provide a local URL.

Open the URL in your web browser to use the chatbot.

## Main Components

### Streamlit Interface

Streamlit is used to create the web-based user interface. It provides components such as:

* Page configuration

### Hugging Face InferenceClient

The `InferenceClient` from the `huggingface_hub` library is used to communicate with the Hugging Face Inference API.

```python
client = InferenceClient(
    api_key=st.secrets["HF_TOKEN"]
)
```

### AI Model

The chatbot uses:

```text
openai/gpt-oss-120b
```

The model receives the user's question and generates an AI-based response.

### Chat Completion

The application sends the user's question through the chat completion API:

```python
response = client.chat.completions.create(
    model="openai/gpt-oss-120b",
    messages=[
        {
            "role": "user",
            "content": question
        }
    ]
)
```

The generated answer is obtained using:

```python
response.choices[0].message.content
```

## Security

The Hugging Face API token is sensitive information.

The following file should not be uploaded to GitHub:

```text
.streamlit/secrets.toml
```

Add it to `.gitignore`:

```text
.streamlit/secrets.toml
```

A `.gitignore` file can contain:

```text
.streamlit/secrets.toml
__pycache__/
*.pyc
```

This prevents sensitive information and unnecessary Python files from being committed to the repository.
